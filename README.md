# Media DL

Twitter(X)の画像、文章、動画を簡単に保存できるChrome拡張機能です。一般サイトの画像保存にも対応しています。

## 主な機能

- **Twitter対応**: 画像、動画、文章ツイートをワンクリックで保存
- **一般サイト対応**: 画像にホバーでダウンロードボタン表示
- **文字ツイート保存**: スクリーンショットまたはテキストファイルとして保存
- **保存先記憶**: 最後に保存したフォルダを自動記憶


## インストール手順

1. 配布ページからZIPファイルをダウンロード
2. ZIPを右クリック →「すべて展開」で解凍（解凍後のフォルダの中に `manifest.json` があります）
3. Chromeで拡張機能のページを開く（chrome://extensions/）
4. 右上の「デベロッパーモード」を有効にする
5. 「パッケージ化されていない拡張機能を読み込む」をクリック
6. 解凍したフォルダを選択

※ 解凍したフォルダは削除・移動しないでください（Chromeがこのフォルダを直接読み込みます）。
※ デベロッパーモードで読み込んだ拡張機能は、Chrome起動時に「デベロッパーモードの拡張機能を無効にしてください」と表示されることがあります。「×」で閉じて問題ありません。
※ アップデートは手動です。新しい版のZIPを解凍し、同じ手順で読み込み直してください。

## 使用方法

### Twitter

【おすすめ】
この拡張機能を使用するにあたり、初期設定として chrome://settings/downloads の保存先を C:\Users\ユーザー名\Pictures にすることで、画像ホバーDL時の保存先指定をする際スムーズに選択できます。

- 仕様説明 -
初回ダウンロード時にエクスプローラーが開き「このサイトに変更の保存を許可する場所を選択してください」と
表示されるので保存したいフォルダーを選択してください（例: `C:\Users\ユーザー名\Pictures`）
以降、指定したフォルダーを元に、月ごとにフォルダが作成され保存した画像は、保存した月のフォルダに保存されていきます。
（例：2026年07月05日に保存すると、「2607」フォルダが作成され、2026年07月中は2607に保存されていきます。
　　　2026年08月になれば、自動的に「2608」が作成され保存されていきます）


1. Twitterの投稿に表示されるダウンロードボタンをクリック
2. 画像・動画は自動的に保存されます
3. 文字ツイートはスクリーンショットとして保存されます

- 保存ファイル名について -
どのボタン（アクションバー／画像ホバー／写真モーダル／スレッド一括／スクリーンショット）から保存しても、
ファイル名は **「ユーザーID_投稿日(YYMMDD)_本文先頭20文字」** の統一形式になります
（例: `O_ayanami_261103_Mococo.jpg`）。複数メディアがあるツイートでは末尾に `_1` `_2` の連番が付きます。
一般サイトでの保存も同じ並び（サイト名_保存日_元のファイル名）です。

- スクリーンショット（PNG）について -
通常クリックでは、本人のツイート単体ではなく、**本人が自分のツイートに付けたリプ（続きのツイート／自己リプ連投）まで** を1枚に含めて保存します。
他人のリプは含めず、本人のツイートでも「他人のリプへの返信」は含めません。続きツイートが無ければ単体だけの画像になります。
ミドルクリックは従来どおり、間に他人が挟まっても投稿者本人のツイートを最後まで集める広いスレッド保存です。


### 一般サイト

1. 画像にホバー
2. 表示されるダウンロードボタンをクリック
3. 保存先を指定して保存します

## 設定

拡張機能のアイコンをクリックして設定画面を開きます。

- **Twitter**: Twitterでの機能を有効/無効
- **一般サイト**: 一般サイトでの機能を有効/無効
- **ホバーボタン位置**: ボタンの表示位置を4箇所から選択
- **保存先フォルダ**: フォルダをリセット


## トラブルシューティング

### 拡張機能が読み込まれない

1. デベロッパーモードが有効になっているか確認
2. 選んだフォルダ直下に `manifest.json` があるか確認（フォルダが二重になっていないか）
3. Chromeを再起動

### ボタンが表示されない

1. 拡張機能の設定で該当サイトが有効になっているか確認
2. ページを再読み込み
3. Chromeを再起動

## ファイル構成

```
media-dl/
├── manifest.json            (拡張機能設定)
├── background.js            (バックグラウンド処理)
├── content.js               (Twitter用)
├── content_generic.js       (一般サイト用)
├── injected.js              (データ取得用)
├── popup.html               (設定画面)
├── popup.js                 (設定画面処理)
├── icons/                   (アイコン)
│   ├── icon16.png
│   ├── icon48.png
│   └── icon128.png

```
