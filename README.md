# Media DL

Twitterの画像・動画・文字ツイートをワンクリックで保存できるChrome拡張機能です。一般サイトの画像保存にも対応しています。

## 主な機能

- Twitter：投稿のボタンから画像・動画を保存。文字ツイートはスクリーンショット（PNG）で保存
- 一般サイト：画像にホバーで出るボタンから保存
- 保存先フォルダを記憶し、月ごとのフォルダ（例：2607）に自動で振り分け

## ダウンロード（クリックですぐ落ちます）

- [拡張機能のZIP](https://github.com/imo-to/Twitter-media-DL/releases/download/v1.1.2/media-dl_v1.1.2.zip)

## インストール

1. 上のリンクからZIPをダウンロードして解凍する（解凍したフォルダ直下に `manifest.json` がある状態にする）
2. Chromeで chrome://extensions を開き、右上の「デベロッパーモード」をONにする
3. 「パッケージ化されていない拡張機能を読み込む」で、解凍したフォルダを選ぶ

※ 解凍したフォルダは削除・移動しないでください（Chromeがそのフォルダを直接読み込みます）。
※ 起動時に「デベロッパーモードの拡張機能を無効にしてください」と出ることがありますが、「×」で閉じて問題ありません。
※ アップデートは手動です。新しいZIPを解凍し、同じ手順で読み込み直してください。

## 使い方

### Twitter

投稿に表示されるダウンロードボタンを押すだけです。

- ファイル名はどのボタンから保存しても「ユーザーID_投稿日(YYMMDD)_本文先頭20文字」で統一（例：`sample_261103_サンプルツイート.jpg`）。複数メディアのときは末尾に `_1` `_2` の連番が付きます
- 初回保存時にフォルダを選ぶ画面が出ます。以後はそのフォルダの中に、月ごとのフォルダを作って保存します
- スクリーンショット（PNG）の通常クリックは、本人の続きツイート（自己リプ連投）まで含めて1枚に保存します。他人のリプは含みません。ミドルクリックはスレッド全体を広く集める保存です
- スムーズに使うコツ：chrome://settings/downloads の保存先を `C:\Users\ユーザー名\Pictures` にしておくと、保存先指定が楽になります

### 一般サイト

画像にホバーして、出てきたボタンを押します。ファイル名は「サイト名_保存日_元のファイル名」です。

## 設定

拡張機能のアイコンから開きます。

- Twitter / 一般サイトの機能の有効・無効
- ホバーボタンの位置（4箇所）
- 保存先フォルダのリセット

## うまく動かないとき

- 読み込まれない：デベロッパーモードがONか、選んだフォルダ直下に `manifest.json` があるか（フォルダが二重になっていないか）を確認し、Chromeを再起動
- ボタンが出ない：設定で対象サイトが有効か確認し、ページを再読み込み
